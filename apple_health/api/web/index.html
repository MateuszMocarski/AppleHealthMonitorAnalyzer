The built-in Apple Watch source is Apple\xa0Watch. It contains a non-breaking space (NBSP / U+00A0) between Apple and Watch. The built-in value matches the standard Apple Watch source family; an explicit override is exact, and a regular space is a different value.
How it works

The app reads your Apple Health export once, generates reports for the selected months, and forgets the uploaded files after the request is finished. Only the ZIP archive and reporting periods are required.

1. Apple Health export

Upload the ZIP archive exported from Apple Health. The archive is processed temporarily and is not stored by the app.

2. Reporting periods

Choose one or more months. The ZIP is parsed once, then a separate report set is generated for every selected month.

3. Optional config.toml

Upload a TOML file when you want to override application defaults such as sleep scoring or data source names. You can download a complete example file from the advanced settings section.

4. Source overrides

These two fields override only the source names used for this request. Leave them blank to keep the value from config.toml or the built-in defaults.

Apple Watch source

The built-in default Apple\xa0Watch uses a non-breaking space (NBSP / U+00A0) and matches standard device-named Apple Watch sources. A value entered here is matched exactly.

Generated files

Selected report outputs are generated for every chosen month. You can choose between full.txt, full.json, summary.txt, and summary.json. Full JSON is selected by default.
